# Мой пет-проект

Идея: Разработка Telegram-бота для мониторинга доступности сетевых сервисов и автоматического оповещения об инцидентах.
Стек: Python (Aiogram), Docker, PostgreSQL, Prometheus client.
Цель: Научиться проектировать отказоустойчивые фоновые сервисы, собирать метрики и автоматизировать их развертывание в изолированных контейнерах.
