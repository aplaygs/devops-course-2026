# Особенности работы с Git в IDE (VS Code) и в терминале (CLI)

## Преимущества работы в IDE (VS Code):
1. Визуальный diff-редактор, позволяющий наглядно сравнивать рабочую версию файла с версией из индекса или последнего коммита.
2. Панель Source Control и расширения (GitLens, Git Graph) для удобного просмотра истории изменений, аннотаций строк (git blame) и визуализации ветвлений.
3. Быстрое выборочное индексирование отдельных фрагментов кода (Stage Selected Ranges) прямо из интерфейса редактора.

## Преимущество работы в терминале (CLI):
1. Универсальность и гарантированная доступность на любых серверах и виртуальных машинах по SSH без графической оболочки, а также возможность полной автоматизации и скриптинга сложных операций (rebase, reflog, cherry-pick).
